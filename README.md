# 点头素材台

静态展示站。页面和图片在 [`gh-pages`](https://github.com/yexiaohanyao/diantou-xhs-material/tree/gh-pages) 分支，准备发布到：

https://yexiaohanyao.github.io/diantou-xhs-material/

登录页任意提交即可进入，不核对账号或密码。1192 张素材图在站点的 `materials/` 目录里，和页面同源，走 HTTPS。

在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 `gh-pages`，目录 `/ (root)`，然后保存。保存之后上面的地址才会开始提供页面。
